# Phase 08 — Production Readiness

## Goal
Practice operating the system, not only deploying it.

## Build
- SLI/SLO definitions for availability and payment processing
- Alert rules tied to user impact
- Database backup + restore drill
- Load/soak tests and capacity baseline
- Incident, rollback, dead-letter and webhook replay runbooks
- Readiness/liveness strategy
- Failure exercises: provider timeout, broker outage, DB pressure, worker restart

## Explore
Error budgets, RTO/RPO, graceful degradation, capacity planning, operational ownership, post-incident learning.

## Definition of done
The team can detect, diagnose, recover from, and document representative failures using tested procedures. Complete the checklist in `../PRODUCTION-READINESS.md` with evidence.
