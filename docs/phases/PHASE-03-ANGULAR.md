# Phase 03 — Angular Experience

## Goal
Turn the backend into a demonstrable merchant operations product.

## Build
- Angular workspace under `src/frontend/payflow-web`
- Application shell and responsive navigation
- Login/auth state
- Dashboard summary and charts
- Payments list/create/detail
- Transactions list/detail with lifecycle timeline
- Filters, pagination, loading/empty/error states
- API client/interceptors and typed models

## Explore
Frontend state boundaries, RxJS patterns, accessible UI, API error UX, design consistency, and avoiding business rules duplicated in the browser.

## Definition of done
A reviewer can complete the core payment journey from the UI and understand transaction state without opening Swagger.
